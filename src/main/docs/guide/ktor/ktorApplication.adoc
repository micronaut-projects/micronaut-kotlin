<1> The `Application` class extends `io.micronaut.ktor.KtorApplication` and declares the Ktor engine type, in this case Netty.
<2> The `applicationEngineEnvironment { ... }` block lets you customize Ktor environment settings used by the Micronaut integration, such as logging.
<3> The `applicationEngine { ... }` block configures engine-specific settings. In this example, the Netty engine configuration sets `workerGroupSize` to `10`.
<4> A `main` method is defined for running the application within a runnable JAR.
