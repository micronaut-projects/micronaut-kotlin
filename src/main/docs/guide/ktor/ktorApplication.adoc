<1> The `Application` class extends `io.micronaut.ktor.KtorApplication` and provides the server type (in this case Netty).
<2> You can optionally configure the Micronaut wrapper for Ktor’s `ApplicationEnvironmentBuilder`.
<3> You can optionally configure the engine. In this case `NettyApplicationEngine.Configuration` is used to set `workerGroupSize` to `10`.
<4> A `main` method is defined for running the application within a runnable JAR
